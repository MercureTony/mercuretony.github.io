
# v0 Component Generation Guidelines

## Process

1. **Component Ideation**
   - Think carefully about the component you want to create
   - Consider its purpose, functionality, and potential user interactions

2. **Prompt Generation**
   - Craft a clear, specific prompt for v0
   - Include details about design, functionality, and any specific requirements

3. **URL Encoding**
   - Encode the prompt to make it URL-safe
   - Use an online URL encoder or a built-in function in your preferred programming language

4. **Create Clickable Link**
   - Use the format: `[component name](https://v0.dev/chat?q={encoded_prompt})`
   - Ensure the encoded prompt is correctly inserted into the URL

5. **Component Creation**
   - Click the generated link to open v0 with your prompt
   - Review and refine the generated component as needed

6. **Documentation**
   - Document any modifications or additional steps taken after v0 generation
   - Update this file with new insights or best practices discovered

## Best Practices

- Be as specific as possible in your prompts
- Include information about desired styling, functionality, and user interactions
- If the first generation doesn't meet your needs, refine your prompt and try again
- Use v0's strengths in UI design and component structure, but be prepared to adjust logic or complex functionality

## Example

### Component: Interactive Pricing Calculator

1. **Ideation**: We need a calculator for a SaaS product that factors in multiple variables and displays dynamic pricing.

2. **Prompt**: "Generate an interactive pricing calculator for a SaaS product. Include inputs for number of seats (1-1000), monthly usage in GB (1-10000), and a dropdown for annual vs monthly billing. Show a dynamic total price that updates in real-time. Use a modern, clean design with a blue and white color scheme. Include a 10% discount for annual billing."

3. **Encoded Prompt**: 

```jsx
'use client'

import { useState, useEffect } from 'react'
import { Input } from '@/components/ui/input'
import { Label } from '@/components/ui/label'
import { Select, SelectContent, SelectItem, SelectTrigger, SelectValue } from '@/components/ui/select'
import { Card, CardContent, CardHeader, CardTitle } from '@/components/ui/card'

export default function Component() {
  const [seats, setSeats] = useState(1)
  const [usage, setUsage] = useState(1)
  const [billingCycle, setBillingCycle] = useState('monthly')
  const [totalPrice, setTotalPrice] = useState(0)

  const basePrice = 10 // Base price per seat
  const usagePrice = 0.5 // Price per GB

  useEffect(() => {
    let price = seats * basePrice + usage * usagePrice
    if (billingCycle === 'annual') {
      price = price * 12 * 0.9 // 10% discount for annual billing
    }
    setTotalPrice(parseFloat(price.toFixed(2)))
  }, [seats, usage, billingCycle])

  return (
    <Card className="w-full max-w-md mx-auto bg-white shadow-lg">
      <CardHeader className="bg-blue-600 text-white">
        <CardTitle className="text-2xl font-bold text-center">SaaS Pricing Calculator</CardTitle>
      </CardHeader>
      <CardContent className="p-6">
        <div className="space-y-4">
          <div className="space-y-2">
            <Label htmlFor="seats">Number of Seats (1-1000)</Label>
            <Input
              id="seats"
              type="number"
              min="1"
              max="1000"
              value={seats}
              onChange={(e) => setSeats(Math.min(1000, Math.max(1, parseInt(e.target.value) || 1)))}
              className="border-blue-300 focus:border-blue-500 focus:ring-blue-500"
            />
          </div>
          <div className="space-y-2">
            <Label htmlFor="usage">Monthly Usage in GB (1-10000)</Label>
            <Input
              id="usage"
              type="number"
              min="1"
              max="10000"
              value={usage}
              onChange={(e) => setUsage(Math.min(10000, Math.max(1, parseInt(e.target.value) || 1)))}
              className="border-blue-300 focus:border-blue-500 focus:ring-blue-500"
            />
          </div>
          <div className="space-y-2">
            <Label htmlFor="billing-cycle">Billing Cycle</Label>
            <Select value={billingCycle} onValueChange={setBillingCycle}>
              <SelectTrigger id="billing-cycle" className="border-blue-300 focus:border-blue-500 focus:ring-blue-500">
                <SelectValue placeholder="Select billing cycle" />
              </SelectTrigger>
              <SelectContent>
                <SelectItem value="monthly">Monthly</SelectItem>
                <SelectItem value="annual">Annual (10% discount)</SelectItem>
              </SelectContent>
            </Select>
          </div>
          <div className="pt-4">
            <p className="text-lg font-semibold text-blue-600">
              Total Price: ${totalPrice} {billingCycle === 'annual' ? 'per year' : 'per month'}
            </p>
            {billingCycle === 'annual' && (
              <p className="text-sm text-green-600 mt-1">You save 10% with annual billing!</p>
            )}
          </div>
        </div>
      </CardContent>
    </Card>
  )
}
```
